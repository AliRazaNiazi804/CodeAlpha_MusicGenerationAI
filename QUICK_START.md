## 🛠️ Troubleshooting

### Issue: "ModuleNotFoundError"
**Solution:**
```bash
pip install --upgrade -r requirements.txt
```

### Issue: Webcam not working in Object Detection
**Solution:**
- Check if another app is using the webcam
- Try using a video file instead
- Restart your computer

### Issue: MIDI files not saving
**Solution:**
```bash
pip install --upgrade music21
```

### Issue: GUI not displaying
**Solution:**
```bash
python -m tkinter  # Test if tkinter is installed
```
